# Spendly 💸

A modern expense tracking mobile application built with React Native and TypeScript.

## Features

- Add expenses with category, amount, and note
- Delete transactions from the detail modal
- Recent transaction history
- Category summary with grouped totals
- Real-time balance calculation
- Statistics screen with pie chart analytics
- Local persistence with AsyncStorage
- Dark theme UI
- Clean and responsive layout

## Tech Stack

- React Native
- TypeScript
- Expo
- React Navigation (Bottom Tabs)
- AsyncStorage
- react-native-chart-kit

## Future Improvements

- Edit transactions
- Income tracking
- Search transactions
- Budget planning
- Export to PDF
